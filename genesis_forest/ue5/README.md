# UE5 Rendering

## Architecture

```
genesis_forest.py  ──►  forest_output.usdc  ──HTTP POST──►  UE5 Python HTTP Server
                                                              │
                                                              ├── EditorScriptingUtilitiesSubsystem
                                                              │   (unreal.get_editor_subsystem())
                                                              │
                                                              └── Lumen + Nanite + Screenshot
```

The USD file generated by Genesis is rendered in UE5 using a Python HTTP server
that runs **inside** UE5 and listens for render commands from the Gradio backend.

## Two Components

### 1. UE5 Server (`ue5_server.py`)
Runs **inside** Unreal Engine 5. Uses `unreal.get_editor_subsystem()` for all
editor operations. Listens on port 8787 for HTTP requests.

### 2. Gradio Client (`client.py`)
Runs in the **normal Python/Gradio** environment (outside UE5). Posts JSON
render requests to the UE5 server and reports results.

## Quick Start

### Step 1: Generate the forest (Gradio or CLI)

```bash
cd genesis_forest
pip install genesis-world gradio numpy scipy noise
python -m examples.ue5_export
# → forest_ue5.usdc
```

### Step 2: Start UE5 and load the server script

1. Open UE5 with your project (or create a blank project)
2. Enable **Python Editor Script Plugin**:
   - `Edit → Plugins → Python Editor Script Plugin → Enabled`
   - Restart UE5 when prompted
3. Open the Python console:
   - `View → Developer Tools → Python Console`
4. Start the server:
   ```python
   exec(open("C:/path/to/genesis_forest/ue5/ue5_server.py").read())
   ```
   You should see:
   ```
   [UE5] Forest render server listening on 0.0.0.0:8787
   [UE5] POST http://localhost:8787/render to trigger a render
   ```

### Step 3: Use the Gradio UI

```bash
cd genesis_forest
python -m gradio_app.app
```

1. Go to the **"Render in UE5"** tab
2. Click **"Check UE5 Status"** — you should see "UE5 Connected"
3. Enter the USD path (e.g., `forest_ue5.usdc`)
4. Set camera position and lighting
5. Click **"Render in UE5"**

The Gradio backend posts an HTTP request to the UE5 server, which:
- Imports the USD stage using `EditorScriptingUtilitiesSubsystem`
- Configures Lumen + Nanite rendering
- Sets up directional sun + sky atmosphere + fog
- Spawns a cinematic camera
- Takes a high-resolution screenshot

## API

### From Gradio (outside UE5)

```python
from ue5.client import render_in_ue5, UE5RenderClient

client = UE5RenderClient(host="localhost", port=8787)

result = client.render_simple(
    usd_path="./forest_output.usdc",
    camera_location=(5000, -5000, 2000),   # world position (cm)
    camera_look_at=(0, 0, 500),              # look-at point (cm)
    resolution=(3840, 2160),                  # 4K
    sun_azimuth=45.0,                        # sun horizontal angle (deg)
    sun_elevation=30.0,                      # sun vertical angle (deg)
)
# result = {"success": True, "output_path": "...", "elapsed_seconds": 12.5, ...}
```

### From inside UE5 (Python console)

```python
from ue5_server import start_server, stop_server, render_scene

start_server(port=8787, background=True)

# Or run a one-shot render:
result = render_scene({
    "usd_path": "C:/path/to/forest_output.usdc",
    "camera_location": [5000, -5000, 2000],
    "camera_look_at": [0, 0, 500],
    "output_path": None,  # auto
    "resolution": [3840, 2160],
    "sun_azimuth": 45.0,
    "sun_elevation": 30.0,
})
```

## `unreal.get_editor_subsystem()` Usage

The server uses `unreal.get_editor_subsystem()` for editor automation:

```python
# Get the EditorScriptingUtilitiesSubsystem for asset import
subsystem = unreal.get_editor_subsystem(unreal.EditorScriptingUtilitiesSubsystem)
if subsystem:
    # Use subsystem methods for importing
    subsystem.import_assets(...)

# Get the EditorPerformanceSubsystem for performance queries
perf = unreal.get_editor_subsystem(unreal.EditorPerformanceSubsystem)
```

Available subsystems (UE5.3+):
- `EditorScriptingUtilitiesSubsystem` — asset import, level operations
- `EditorPerformanceSubsystem` — performance monitoring
- `BlueprintEditorSubsystem` — blueprint operations

## Rendering Settings

| Setting | Console Command | Effect |
|---------|----------------|--------|
| Lumen GI | `r.Lumen.Enable 1` | Dynamic global illumination |
| Nanite | `r.Nanite.Enable 1` | Micro-triangle geometry |
| Virtual Shadow Maps | `r.Shadow.Virtual.Enable 1` | Soft shadows |
| Auto Exposure | `r.DefaultFeature.AutoExposure 1` | Eye adaptation |
| Anti-aliasing | `sg.AntiAliasingQuality 3` | TSRAA |

## Troubleshooting

### "unreal module not found"
The `unreal` module is only available **inside UE5** with the Python Editor
Script Plugin enabled. The `ue5_server.py` and `client.py` modules are designed
to run in different environments:

- `ue5_server.py` → **inside UE5** (Python console)
- `client.py` → **normal Python** (Gradio backend)

### "Connection refused" when clicking Render in UE5
1. Make sure UE5 is running
2. Make sure the server script is loaded in UE5's Python console
3. Check the port matches (default 8787)
4. Check your firewall allows the connection

### Screenshot is black or UE5 hangs
- Use `-game` mode, not `-batchmode`
- The game viewport must be visible
- If UE5 freezes, the screenshot may be too large — try 1920×1080 first

### USD import fails
- Make sure the USDImporter plugin is enabled in UE5
- Use `.usdc` (binary) for best compatibility
- Check that the USD file path is accessible from UE5's filesystem
